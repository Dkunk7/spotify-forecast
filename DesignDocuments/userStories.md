# User Stories
___
## MVP User Stories
___
### User Authentication and Account Management
#### Sign Up *
As a new user I want to create an account so that I can save forecast locations and playlists.
#### Sign In *
As a registered user I want to log in so that I can check my forecast and save playlists.
#### Password Reset *
As a registered user, I want to be able to reset my password if I forget it.

### Weather Viewing
#### Find Current Weather Results by Location Name *
As a visitor I want to be able to search for a location and get the current weather for that location.

### Weather Saving
#### Save Locations for Future Viewing *
As a registered user I want to be able to save specific locations in order to easily check the weather there later.

### Spotify Playlist Viewing
#### See Playlist Recommendation for Current Weather *
As a visitor I want to be able to see a playlist recommended based on the current weather of the location I'm viewing

### Spotify Playlist Saving
#### Save Playlist Recommendation for Future Access *
As a registered user I want to be able to save recommended playlists so that I can access them later.
___
## Non-MVP User Stories
___
## Weather Viewing
#### Find Future Weather Forecast by Location Name *
As a visitor I want to be able to search for a location and get the future forecast for that location.

## Spotify Playlist Viewing
#### See Playlist Recommendation for Future Forecast
As a visitor I want to be able to see a playlist recommended for each day in the future forecast.
