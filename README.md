# Spotify Forecast
___
## Problem Statement
People use weather apps every day, whether they're checking the weekly forecast or simply looking at the current
conditions on the way out the door. There are many options for weather apps, too, but for the most part, they're all
very similar. Yeah, you can keep track of the weather, but we've always been able to do that. None of them offer
anything special.

Spotify Forecast will not only show you the weather conditions you're looking for, but will also suggest Spotify playlists
based on the mood of the current weather.
